# Ευθύνη του backend

Οι δύο εκφωνήσεις και το αρχικό prompt αντιμετωπίζονται ως πηγές απαιτήσεων, με διακριτές αρμοδιότητες. Η έκδοση 1.1.1 υποστηρίζει τις αλληλεπιδράσεις επιλογής χώρου, επιθεώρησης μετρήσεων, πρόβλεψης, επιβεβαίωσης, αναγνώρισης κατάστασης και ελέγχου αποτελέσματος. Παρέχει εννέα καθαρές συναρτήσεις φυσικής, υπερκαλύπτοντας το ελάχιστο των πέντε της πλήρους εκφώνησης (σελ. 5), των τριών της Εργασίας 1 και των επτά ομάδων του prompt.

Η επιτυχία HTTP200 επιβεβαιώνει το δηλωμένο στάδιο: για ένα πρόγραμμα σημαίνει αποθήκευση προγραμματισμού, για στόχο θερμοκρασίας εφαρμογή στόχου, για rover το στάδιο παραλαβής/εκτέλεσης της συγκεκριμένης εντολής. Η πραγματική φυσική εξέλιξη παρατηρείται αργότερα. Αυτό είναι ουσιώδες για το χάσμα αξιολόγησης του Norman.

Η υλοποίηση είναι τοπική εκπαιδευτική προσομοίωση. Η επιλογή `X-Id-Xristi` δηλώνει λογαριασμό επίδειξης χωρίς κωδικό ή κρυπτογραφικό αποδεικτικό ταυτότητας. Οι αναγνώσεις είναι δημόσιες στην τοπική εγκατάσταση. Δεν παρέχεται δικτυακή αυθεντικοποίηση για δημόσια διάθεση. Η SQLite σειριοποιεί τις εγγραφές· οι χρόνοι προσομοίωσης εξελίσσονται μόνο με ρητή εντολή βήματος. Δεν υπάρχει πραγματική συσκευή, ραδιοζεύξη ή εξωτερική τηλεμετρία.

Τα φυσικά μοντέλα έχουν δηλωμένες εκπαιδευτικές παραδοχές. Τα τελικά διαγράμματα HTA/Norman, οι οθόνες, τα πραγματικά screenshots, οι δοκιμές με χρήστες, τα ονόματα ομάδας και η ομαδική υποβολή `ergasia1.zip` παραμένουν ευθύνη της ομάδας. Η ολοκλήρωση του backend δεν πιστοποιεί την ολοκλήρωση αυτών των παραδοτέων.
