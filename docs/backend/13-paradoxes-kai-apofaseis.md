# 13 - Παραδοχές και Αρχιτεκτονικές Αποφάσεις (ADR)

## ADR-01: Επιλογή SQLite με Ενεργοποιημένα Ξένα Κλειδιά
- **Πλαίσιο:** Το σύστημα είναι εκπαιδευτική προσομοίωση που απαιτεί εύκολη τοπική εκτέλεση χωρίς εξωτερικές υπηρεσίες (zero-dependency local setup).
- **Απόφαση:** Χρήση SQLite 3. Σε κάθε σύνδεση SQLAlchemy εκτελείται αυτόματα `PRAGMA foreign_keys = ON;` ώστε να αποτρέπονται ορφανές εγγραφές. Για τις δοκιμές χρησιμοποιείται `sqlite:///:memory:` με `StaticPool` για αποφυγή ασυμβατοτήτων συνδέσεων.
- **Συνέπειες:** Μηδενικό κόστος εγκατάστασης, εξαιρετική ταχύτητα εκτέλεσης δοκιμών, πλήρης αξιοπιστία αναφορών.

---

## ADR-02: Αυστηρός Κανόνας Ονοματοδοσίας Greeklish (§0A)
- **Πλαίσιο:** Η απαίτηση του έργου επιβάλλει χρήση λατινικής μεταγραφής της ελληνικής γλώσσας (ASCII Greeklish) για όλα τα ονόματα αναγνωριστικών στον κώδικα, τα schemas, τους πίνακες και τα API endpoints.
- **Απόφαση:** Δημιουργία επίσημου γλωσσαρίου (`docs/backend/17-kanones-onomatodosias.md`) και επιβολή αυτοματοποιημένης δοκιμής (`test_greeklish_naming_standards`) που αναλύει το OpenAPI schema και διασφαλίζει ότι κανένα endpoint ή property δεν παραβιάζει τον κανόνα.
- **Εξαιρέσεις:** Μόνο αναγνωριστικά βιβλιοθηκών (FastAPI, Pydantic, SQLAlchemy), αρχεία διαμόρφωσης (`pyproject.toml`, `alembic.ini`), τυποποιημένες μονάδες SI (`kW`, `kWh`, `kg`, `K`, `L`, `Pa`) και επικεφαλίδες HTTP (`Content-Type`, `Idempotency-Key`).

## ADR-03: Απομόνωση Φυσικών Μοντέλων σε Αμιγείς Συναρτήσεις (Pure Functions)
- **Πλαίσιο:** Τα φυσικά μοντέλα πρέπει να ελέγχονται με απόλυτη μαθηματική ακρίβεια ανεξάρτητα από τη βάση δεδομένων.
- **Απόφαση:** Υλοποίηση όλων των φυσικών υπολογισμών (PHY-01 έως PHY-07) σε ξεχωριστό άρθρωμα χωρίς εισαγωγές SQLAlchemy ή FastAPI.
- **Συνέπειες:** 100% ντετερμινισμός, ταχύτατα unit tests, πλήρης επαληθευσιμότητα των χρυσών τιμών (golden numbers).

---

## ADR-04: Μοτίβο Δύο Βημάτων (Preview / Confirm Pattern)
- **Πλαίσιο:** Σε ακραία περιβάλλοντα όπως ο Άρης, μια εσφαλμένη εντολή (π.χ. υπερβολική άρδευση ή απότομη θέρμανση) μπορεί να εξαντλήσει ζωτικούς πόρους.
- **Απόφαση:** Κάθε σημαντική ενέργεια απαιτεί προεπισκόπηση (`POST .../proepiskopisi`), η οποία επιστρέφει εκτιμώμενες επιπτώσεις και ένα `id_proepiskopisis`. Η ενέργεια οριστικοποιείται μόνο μετά από ρητή επιβεβαίωση (`POST .../epivevaiwsi`).
- **Συνέπειες:** Αποτροπή ανθρώπινου λάθους, ευθυγράμμιση με τα πρότυπα HTA και τις 7 φάσεις δράσης του Norman.

## ADR-05: Αποτροπή Διπλής Εκτέλεσης με Idempotency Key
- **Πλαίσιο:** Λόγω καθυστερήσεων ή επαναλήψεων δικτύου, μια εντολή επιβεβαίωσης μπορεί να σταλεί πολλαπλές φορές.
- **Απόφαση:** Υποστήριξη της επικεφαλίδας `Idempotency-Key`. Αν ληφθεί δεύτερο αίτημα με το ίδιο κλειδί, το σύστημα δεν εκτελεί ξανά τη δράση αλλά επιστρέφει την αποθηκευμένη απόκριση της αρχικής εκτέλεσης.
